`main.py` (Python 3 standard library only) writes a two-line family scene to `output/entry.txt`.

## Run it

```sh
python3 main.py
```

## The scene

**Every Sunday, Dad sets a fourth plate for Grandma, then winks at me: "She's just late again."
Twenty years late -- and somehow dinner still tastes like she's on her way home.**

Two lines, 174 characters. A Sunday-dinner ritual: Dad still sets a plate for a grandmother gone twenty years, and the wry "she's just late again" keeps her at the table — warm, a little funny, and heartfelt rather than sentimental. The program validates the gate locally (1–280 characters, non-whitespace, one or two lines, valid UTF-8) before writing.
